# 实验三：加入对抗样本后重新训练

已完成完整数据实验，详见 [实验结果分析](实验结果分析.md)。本次正常准确率从 98.70% 变为 98.91%，但 ε=0.2 的 FGSM 后准确率从 28.62% 降至 6.63%，PGD 后准确率为 0%。因此本次固定样本增强未达到防御目标。

本实验基于实验一的 FGSM，以既有 MNIST 模型为起点，从**训练集**生成固定对抗样本，再将它们与正常训练图片混合，继续训练模型。正常测试集和攻击测试集均不参与训练。本实验不修改已有 FGSM/PGD 代码、模型或结果。

## 实验设计

1. 加载 `../FGSM/outputs/mnist_cnn.pt`，作为原始模型 Baseline。
2. 用该模型对 MNIST 的 60,000 张训练图片生成 FGSM 样本，ε=0.2，保留真实标签。
3. 将 60,000 张正常图片与 60,000 张对抗图片按 1:1 混合。每个训练批次同时包含对应的正常图片与对抗图片。
4. 从原模型权重继续训练 5 轮，得到 FGSMAugmented 模型。Adam 学习率 0.001，混合后批量大小 256，随机种子 42。
5. 额外训练 CleanControl：同样从原模型继续训练 5 轮，但只使用重复两遍的干净训练集，以保持每轮样本数、批量大小和优化步数一致。该对照帮助区分“额外训练”的影响和“加入对抗样本”的影响；两组批次的样本组合并不完全相同。
6. 对三个模型使用相同 10,000 张正常测试图片，并分别针对每个模型重新生成白盒 FGSM 和 PGD 攻击。PGD 默认 40 步、α=0.01、随机起点，ε=0、0.1、0.2、0.3。

这里的“重新训练”采用已有权重微调，不是从随机权重重新训练。固定增强数据在初始模型上一次性生成，训练期间不刷新；这严格对应“把生成的对抗样本加入数据集”的实验方式。它与每一步都针对当前模型重新生成攻击的在线对抗训练有区别。

混合数据的训练目标为：

$$L(\theta)=\frac{1}{2}J(\theta,x,y)+\frac{1}{2}J(\theta,x_{adv}^{fixed},y).$$

不能把测试集生成的攻击样本加入训练，否则产生数据泄漏。也不能仅用旧模型生成的测试攻击评估新模型，那只能衡量迁移攻击；本脚本针对每个待测模型重新计算攻击梯度。

## 运行

在本目录打开终端，使用之前能运行 FGSM 和 PGD 的环境：

```powershell
conda activate content-security
python adversarial_training.py
```

依赖已在此前实验环境中安装；如缺失，可运行 `python -m pip install -r requirements.txt`。保留同级 `FGSM` 和 `PGD` 目录，因为脚本复用其算法和模型定义。默认自动选择 CUDA。

小规模流程验证：

```powershell
python -m unittest -v
python adversarial_training.py --epochs 1 --train-limit 64 --test-limit 32 --epsilons 0 0.2 --pgd-steps 2 --output-dir outputs_smoke
```

完整实验默认评估两个继续训练模型和原始模型，需要比单独攻击更多时间。`--save-adversaries` 可以额外保存生成的训练攻击张量，完整数据约占 188 MB；默认只在内存中混合使用。`--train-epsilon` 控制生成训练攻击的预算，`--epsilons` 控制评估攻击的预算，两者用途不同。相同输出目录的同名文件会被覆盖。

## 输出与结论依据

输出到本目录的 `outputs/`：

| 文件 | 内容 |
| --- | --- |
| `CleanControl.pt` | 额外干净训练的对照模型 |
| `FGSMAugmented.pt` | 加入固定 FGSM 样本后训练的模型 |
| `metrics.csv`、`results.json` | 三个模型的正常准确率、攻击后准确率及攻击成功率，附训练记录和配置 |
| `defense_comparison.png` | 正常准确率及两种攻击下的模型对比 |
| `training_adversaries.pt` | 仅启用 `--save-adversaries` 时生成 |

正常准确率回答“防御是否损害正常识别能力”；攻击后准确率回答“防御是否提高了受攻击时的识别能力”。成功率按各模型自身原本分类正确的样本数计算，因此比较不同模型时应同时报告正常准确率和攻击后准确率。

如果正常准确率保持较高、在相同攻击设置下攻击后准确率提高，说明在本次设置下取得一定防御效果。如果只抵御 FGSM、PGD 下仍表现很差，则不能宣称实现了普遍有效的防御。固定攻击增强可能过拟合旧攻击；进一步的改进可使用针对当前模型动态生成样本的 PGD 对抗训练。

原始模型已预先使用完整 MNIST 训练集训练；子集运行只是流程检查，不是“只见过子集数据”的模型实验。默认超参数预先固定，未根据测试集选择最佳轮次。单次运行结果不等同于多随机种子统计结论，也不能证明对所有攻击的鲁棒性。

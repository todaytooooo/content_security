# 在 MNIST 上实现 PGD 对抗攻击

参考：Aleksander Madry 等，*Towards Deep Learning Models Resistant to Adversarial Attacks*，ICLR 2018，https://arxiv.org/abs/1706.06083 。本实验实现其常用的 L∞ 约束、白盒、非定向 PGD 攻击，不是论文全部对抗训练流程或原始数值的逐项复现。

## 算法原理

攻击目标是在不超过扰动预算的范围内，增大模型对真实标签的交叉熵损失：

$$\max_{\|x'-x\|_\infty\le\epsilon,\;x'\in[0,1]^d}J(\theta,x',y).$$

默认从原图附近随机开始：

$$x^{(0)}=\operatorname{clip}_{[0,1]}(x+u),\qquad u_i\sim U(-\epsilon,\epsilon).$$

然后重复 T 次：

$$x^{(t+1)}=\Pi_{[x-\epsilon,x+\epsilon]\cap[0,1]^d}\left(x^{(t)}+\alpha\operatorname{sign}(\nabla_{x^{(t)}}J(\theta,x^{(t)},y))\right).$$

ε 是每个像素相对**原图**的最大改动；α 是每次更新的步长；T 是迭代次数。每一步投影都相对原图，而不是上一步图片，否则扰动可能累计超过 ε。像素采用 `ToTensor()` 的 [0,1] 尺度，不另作标准化。

| 对比项 | FGSM | 本实验 PGD |
| --- | --- | --- |
| 梯度计算 | 一次 | 每一步重新计算 |
| 更新幅度 | ε | 每步 α，总改动受 ε 约束 |
| 起点 | 原图 | 默认随机扰动后裁剪 |
| 计算成本 | 低 | 约 T 次输入反向传播 |

PGD 通常攻击更强，但有限步数、步长和随机起点不保证对每个样本都胜过 FGSM。本实现每个样本只采用一次随机起点并返回最后迭代，不执行多次重启或最优迭代筛选，不能把测得的准确率视为已证明的鲁棒性下界。

## 运行方法

保留同级 `FGSM` 目录：脚本复用其中的 CNN、训练函数及 FGSM 基线，默认读取 `../FGSM/outputs/mnist_cnn.pt` 和 `../FGSM/data`，因此无需重新训练或下载已有数据。

在本目录打开终端，切换到已经能运行 FGSM 的 Python 环境：

```powershell
conda activate content-security
python -m pip install -r requirements.txt
python pgd_mnist.py
```

如果你使用其他环境，激活对应环境即可。默认在全部 10,000 张测试图片上评估，ε 为 0、0.05、0.1、0.15、0.2、0.25、0.3，α=0.01，T=40，随机种子 42，自动选择 CUDA 或 CPU。ε=0 始终加入评估。完整评估需要比 FGSM 更多时间。

先用小规模数据检查流程（不能视为完整数据集结果）：

```powershell
python pgd_mnist.py --test-limit 256 --epsilon 0 0.1 0.3 --steps 10 --output-dir outputs_smoke
```

自定义攻击参数，或重新训练：

```powershell
python pgd_mnist.py --epsilons 0 0.1 0.2 0.3 --alpha 0.01 --steps 40
python pgd_mnist.py --train --epochs 5 --output-dir outputs_retrained
```

`--checkpoint PATH` 可指定其他同架构模型；`--no-random-start` 禁用随机起点。脚本默认路径相对脚本所在目录，命令中明确给定的相对路径则相对当前工作目录。相同输出目录会覆盖同名结果。随机种子有助于复现，但跨硬件、依赖版本和批量大小不保证随机起点及结果完全一致。

## 输出与分析

| 输出文件 | 内容 |
| --- | --- |
| `outputs/metrics.csv` | 同一模型、同一测试样本上 FGSM 和 PGD 的各档 ε 指标 |
| `outputs/results.json` | 运行配置、设备、PyTorch 版本及指标 |
| `outputs/accuracy_comparison.png` | 两种攻击的准确率对比曲线 |
| `outputs/examples_eps_*.png` | PGD 原图、实际扰动及对抗图 |
| `outputs/mnist_cnn.pt` | 仅在 `--train` 时生成的新模型权重 |

对抗准确率的分母是全部被评估图片；攻击成功率的分母是原本分类正确的图片。原本正确数量为 0 时成功率为空。示例图只选攻击成功且原本正确的样本（ε=0 显示干净样本）；如果没有可选样本，则不生成该 ε 的示例图。扰动色阶按 ε 缩放，不代表实际灰度变化看起来同样明显。

分析时先检查 ε=0 的两种攻击准确率均等于干净准确率，再比较相同 ε 下的 FGSM/PGD 结果。此前你的 FGSM 完整实验干净准确率为 98.70%，ε=0.3 时准确率为 7.43%；默认复用相同模型和完整测试集时，可以将新结果与之核对。PGD 指标必须以实际生成的文件为准。

## 验证

### 本地实测结果（2026-10-28）

已复用 FGSM 模型，在 CUDA、PyTorch 2.6.0+cu126 上完成全部 10,000 张测试图片的评估，使用默认随机起点、α=0.01、40 步。干净准确率为 98.70%。

| ε | FGSM 对抗准确率 | PGD 对抗准确率 | PGD 攻击成功率 |
| --- | --- | --- | --- |
| 0 | 98.70% | 98.70% | 0.00% |
| 0.05 | 94.03% | 92.57% | 6.21% |
| 0.10 | 81.05% | 66.71% | 32.41% |
| 0.15 | 55.29% | 18.72% | 81.03% |
| 0.20 | 28.62% | 1.48% | 98.50% |
| 0.25 | 13.20% | 0.02% | 99.98% |
| 0.30 | 7.43% | 0.00% | 100.00% |

相同模型与扰动预算下，本次 PGD 比 FGSM 更有效。例如 ε=0.15 时，对抗准确率由 FGSM 的 55.29% 降至 PGD 的 18.72%。ε=0.3 时，原本正确的 9,870 张图片全部被 PGD 攻击成功。这表明该普通训练模型对本次 PGD 设置缺乏鲁棒性；不代表所有模型都可被完全攻破，也不代表这些扰动都不可察觉。

ε=0 基线一致，全部批次的像素范围、有限性及扰动预算检查通过。最大扰动与预算之间约 10⁻⁸ 量级的差异是浮点舍入误差。4 项算法单元测试全部通过。

```powershell
python -m unittest -v
```

测试包含：ε=0 不改变图片；大步长下仍满足像素边界和扰动预算；原图、模型参数及参数梯度不被修改；禁用随机起点且 T=1、α=ε 时与 FGSM 一致；非法参数被拒绝。实际评估还逐批检查扰动预算、像素范围、数值有限性及 ε=0 基线。
